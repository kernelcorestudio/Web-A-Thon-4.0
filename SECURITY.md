# Security Policy — NIRVAN '26

## 🛡️ Supported Versions

We actively support and maintain the latest release of the NIRVAN '26 platform.

| Version | Supported          |
| :---    | :---               |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## 🔒 Reporting a Vulnerability

If you discover a security vulnerability or exploit within this project:

1. **Do not create a public GitHub issue.**
2. Email the core team privately at: `kernelcorestudio2026@gmail.com`
3. Include detailed steps to reproduce the vulnerability, along with payload samples and affected endpoints or components.
4. The security team will acknowledge receipt within 24–48 hours and work on an immediate patch.

---

## 🔐 Security Best Practices Implemented
- Client-side input sanitization for all registration inputs.
- Safe WebGL execution without arbitrary code injection.
- Zero external tracking cookies or intrusive third-party scripts.
